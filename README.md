# Blog preview card

A simple Frontend Mentor challenge solution built with plain HTML and CSS. The page displays a blog preview card with a highlighted category label, publication date, article title, description, and author information.

## Overview

This project recreates the design for a blog preview card using:

- Semantic HTML structure
- CSS custom properties
- Flexbox layout
- Custom font styling
- Responsive center-aligned card layout

## Project files

- `index.html` – page structure and content
- `styles/index.css` – styling, layout, colors, and typography
- `assets/images` – illustration and avatar assets
- `assets/fonts` – local font files used for the design

## Preview locally

Open the project in a browser by either:

1. Opening `index.html` directly, or
2. Serving the folder locally with a simple HTTP server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Challenge details

This is a solution to the Frontend Mentor challenge: "Blog preview card".

The design includes:

- a centered card on a warm yellow background
- a rounded article image
- a category badge labelled "Learning"
- publication date
- article heading and summary
- author row with avatar and name
